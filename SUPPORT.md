# Support

- **Bugs and ideas:** [open an issue](https://github.com/p4inz-code/repose-vault/issues/new/choose). Include your OS, the Repose version (Settings → About), and any output from **Settings → Blue & Purple Team Security Audit**.
- **Chat:** [Discord](https://discord.gg/8UKt8s5FbW)
- **Security problems:** see [SECURITY.md](SECURITY.md) — please report privately.

Repose is made by one person, so replies can take a little while.
